# BuildSource Landing Page

Esta é uma landing page simples e responsiva para a BuildSource, que permite que os usuários entrem em contato via WhatsApp.

## Estrutura do Projeto

- `index.html`: A página principal da landing page.
- `style.css`: Estilos para a landing page.
- `script.js`: Lógica para o formulário de contato e redirecionamento para o WhatsApp.
- `README.md`: Documentação do projeto.
- `package.json`: Configurações do projeto.
